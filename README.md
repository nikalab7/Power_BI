# Power BI Projects

This folder contains business intelligence dashboards created using Power BI. These projects demonstrate practical experience in data modeling, DAX calculations, KPI design, and business-focused data visualization.

The dashboards are designed to support data-driven decision making across financial, operational, and HR use cases.

## Investment Portfolio Dashboard

This dashboard provides an overview of an investment portfolio across multiple countries and currencies. It helps track portfolio performance and analyze risk and return trends.

### Key areas covered:
- Total investment and total return overview
- Volatility index analysis
- Investment distribution by country
- Return analysis by currency
- Forecasted vs actual return comparison
- Commission analysis

This dashboard supports portfolio monitoring and high-level financial performance analysis.

## Hotel Performance Dashboard

This dashboard focuses on hotel business performance and booking behavior. It is designed to help analyze revenue, guest activity, and booking trends.

### Key areas covered:
- Net revenue by room type and booking source
- Guest count trends over time
- Average booking period by country
- Booking behavior analysis
- Performance comparison across markets

This dashboard helps identify revenue drivers and understand customer booking patterns.

## HR Analytics Dashboard

This dashboard provides a high-level view of workforce and HR metrics. It supports basic workforce planning and HR performance analysis.

### Key areas covered:
- Headcount trends
- Hiring and termination analysis
- Employee distribution by contract type
- Gender and age group breakdown
- Average employee age and tenure
- Monthly hiring and termination trends

This dashboard helps visualize workforce structure and key HR indicators.
